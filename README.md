# Portfolio — Joseph Halle

Portfolio de Joseph Halle, étudiant en Bachelor Data, Applied AI & Business à Eugenia School.
Site statique (HTML, CSS, JS), sans dépendance, publié avec GitHub Pages.

## Voir le site en local

Ouvrir `index.html` dans un navigateur.

## Mettre à jour le planning des hackathons

Modifier la liste `hackathons` en haut de `script.js` :
- `status` : `"a-venir"`, `"inscrit"` ou `"termine"`
- `result` (facultatif) : le résultat une fois le hackathon passé, par exemple `"2e place sur 18 équipes"`

## Publier avec GitHub Pages

Settings > Pages > Source : branche `main`, dossier `/ (root)`.
Le site sera en ligne sur https://josephhalle-dev.github.io/portfolio-joseph-halle-/
